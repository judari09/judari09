## 🌟 Proyectos Destacados

### 🔎 OpsSleuth

**AI Agent for Operational Investigation & Diagnosis**

Agente de IA diseñado para investigar incidentes operativos utilizando diferentes fuentes de información.

* 🤖 Agentes y tool use
* 🗄️ Búsqueda sobre bases de datos
* 📄 Análisis de archivos de logs
* 🔍 Investigación estructurada de incidentes
* 🧠 Diagnóstico asistido por IA

El proyecto explora cómo acotar y estructurar el trabajo de un agente para investigar problemas reales sin depender de que un desarrollador revise manualmente grandes cantidades de información.

---

### 📝 AIscanner

**Local AI-powered handwritten note scanner**

Aplicación completamente local para transformar notas manuscritas en documentos estructurados.

* 👁️ PaddleOCR para extracción de texto
* 🤖 Ollama + modelos multimodales para corrección y estructuración
* 📝 Conversión a Markdown
* 📐 Interpretación de diagramas dibujados a mano
* 🔒 Procesamiento completamente local
* 🐍 Python + uv

Proyecto enfocado en explorar una arquitectura donde **OCR y LLM tienen responsabilidades diferentes dentro de un mismo pipeline de IA**.
